What are Discord timestamps, and why use them?+

A Discord timestamp is not simple plain text, it's a timezone conversion. When you send <t:1786954860:D> in a message, Discord doesn't store the words "August 17, 2026." It stores a single point in time, then renders it in each reader's own timezone and language automatically. Someone in London and someone in Los Angeles see different clock times, but they're both looking at the same moment.

It's most impactful for anything time-sensitive in a server with people spread across timezones; e.g. event start times, deadlines, "see you at" messages. Typing "9pm" leaves everyone guessing whose 9pm you mean. A timestamp code removes the guesswork entirely.

The seven format options above control how it reads, not what time it represents: R gives a self-updating "in 3 hours" or "2 days ago," F spells out the full date and day of the week, and so on. Pick whichever fits the message, then paste the generated code straight into your Discord message.
